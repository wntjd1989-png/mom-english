# 설치 가이드 (처음부터)

iOS 개발이 처음이라고 가정하고 썼습니다. 순서대로 따라가세요.

---

## 0단계 — 준비물 확인

| 필요한 것 | 비고 |
|---|---|
| **Mac** | macOS Sequoia 이상 권장. Windows/리눅스에서는 iOS 앱을 빌드할 수 없습니다. |
| **Xcode 16 이상** | App Store 에서 무료 설치. 용량이 약 10GB 이고 설치에 30분~1시간 걸립니다. |
| **iPhone (iOS 17 이상)** | 제어 센터 컨트롤까지 쓰려면 iOS 18 이상. |
| **Apple ID** | 무료. |
| **Apple Developer Program** | **유료 $99/년.** 아래 설명을 꼭 읽어 주세요. |
| **USB 케이블** | 첫 설치 때 Mac 과 iPhone 연결용. |

### 유료 계정이 꼭 필요한가요?

이 앱의 핵심 권한 두 개 때문입니다.

- **Hotspot Configuration** — 특정 Wi-Fi 로 전환하는 권한. **이게 없으면 앱의 존재 이유가 없습니다.**
- **Access WiFi Information** — 현재 연결된 Wi-Fi 이름을 읽는 권한.

무료 개인 팀(Personal Team)에서는 이 권한들이 제공되지 않을 가능성이 높습니다.
빌드와 설치는 되지만 전환 버튼을 누르면 오류가 납니다.

**추천 순서:** 먼저 무료 계정으로 빌드해 보세요. 앱이 뜨고 UI 가 동작하는 것까지
확인한 뒤, 전환이 실패하면 그때 유료 가입을 결정하시면 됩니다.
(무료 계정은 설치한 앱이 **7일 뒤 실행되지 않으므로** 다시 빌드해야 합니다.)

## 1단계 — Xcode 설치 후 첫 설정

1. Xcode 를 한 번 실행해서 추가 구성요소 설치를 끝냅니다.
2. **Xcode > Settings > Accounts** → `+` → Apple ID 로 로그인합니다.
3. 로그인하면 Team 목록에 본인 팀이 보입니다.
   `(Personal Team)` 이라고 적혀 있으면 무료 계정입니다.
   **이 팀 이름 옆의 10자리 Team ID 를 메모해 두세요.**

---

## 2단계 — 터미널 도구 설치

터미널(응용 프로그램 > 유틸리티 > 터미널)을 열고:

```bash
# Homebrew 가 없다면 먼저 설치 (있으면 건너뛰기)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# XcodeGen 설치 — project.yml 로 Xcode 프로젝트 파일을 만들어 줍니다
brew install xcodegen
```

> `.xcodeproj` 파일을 저장소에 커밋하지 않는 이유: 수만 줄의 기계 생성 파일이라
> 충돌이 잦고 읽을 수 없습니다. `project.yml` 한 장으로 언제든 재생성합니다.

## 3단계 — 소스 받고 번들 ID 바꾸기

```bash
git clone https://github.com/wntjd1989-png/mom-english.git
cd mom-english/ios-wifi-switcher
git checkout claude/iphone-wifi-control-widget-dhcmzv

# 번들 ID 를 본인 것으로 교체 (예시값 그대로 두면 안 됩니다)
./scripts/set-bundle-id.sh com.본인이름.wifiswitcher
```

번들 ID 는 전 세계에서 유일해야 합니다. `com.` + 본인 이름/도메인 + `.wifiswitcher`
형태를 쓰세요. 예: `com.seongjun.wifiswitcher`

> 이 스크립트는 번들 ID 가 들어가는 **네 곳**(`AppGroup.swift`, `project.yml`,
> entitlements 2개)을 한 번에 고칩니다. 하나라도 어긋나면 **위젯이 네트워크
> 목록을 읽지 못합니다.** 반드시 스크립트로 바꾸세요.

## 5단계 — Xcode 에서 서명·권한 설정 ⭐ 가장 중요

왼쪽 파일 목록 맨 위의 파란 **WiFiSwitcher** 아이콘을 클릭하면 타깃 두 개가 보입니다.

### 5-1. `WiFiSwitcher` 타깃 (앱 본체)

**Signing & Capabilities** 탭에서:

1. **Team** → 본인 팀 선택
2. **Automatically manage signing** 체크
3. `+ Capability` 버튼으로 **세 개**를 추가:
   - `App Groups` → `+` → `group.com.본인이름.wifiswitcher` 입력 후 **체크**
   - `Hotspot Configuration`
   - `Access WiFi Information`

> 목록에 `Hotspot Configuration` 이 없으면 무료 계정이라서 그렇습니다.
> 일단 건너뛰고 진행하세요. 앱은 뜨지만 전환은 실패합니다.

### 5-2. `WiFiControls` 타깃 (위젯 + 컨트롤)

**Signing & Capabilities** 탭에서:

1. **Team** → 같은 팀 선택
2. `+ Capability` → `App Groups` → **앱 본체와 똑같은** `group.com.본인이름.wifiswitcher` 체크

> 위젯 타깃에는 Hotspot Configuration 이 **필요 없습니다.** 실제 전환은 앱
> 프로세스에서 일어나기 때문입니다.

### 5-3. 확인

두 타깃 모두 Signing 영역에 빨간 오류가 없어야 합니다.
`Failed to register bundle identifier` 가 나오면 번들 ID 가 이미 누가 쓰는
것이므로 3단계로 돌아가 다른 이름으로 바꾸세요.

## 6단계 — iPhone 에 설치

1. iPhone 을 USB 로 Mac 에 연결하고, iPhone 에서 **"이 컴퓨터를 신뢰"** 를 누릅니다.
2. iPhone 에서 **설정 > 개인정보 보호 및 보안 > 개발자 모드** 를 켜고 재시동합니다.
   (iOS 16 이상에서 필수입니다.)
3. Xcode 상단 가운데의 실행 대상에서 본인 iPhone 을 선택합니다.
4. `⌘R` (또는 ▶ 버튼)을 누릅니다.

처음 실행하면 iPhone 에 "신뢰하지 않은 개발자" 경고가 뜹니다.
**설정 > 일반 > VPN 및 기기 관리** 에서 본인 Apple ID 를 **신뢰** 하면 됩니다.

---

## 7단계 — 앱에서 Wi-Fi 등록

1. 앱을 열고 우측 상단 `+` 를 누릅니다.
2. **QR 코드 스캔** — 공유기에 Wi-Fi QR 이 붙어 있으면 이게 가장 빠릅니다.
   **직접 입력** — SSID 와 비밀번호를 손으로 넣습니다.
3. SSID 는 **설정 > Wi-Fi 에 보이는 이름을 대소문자까지 그대로** 입력해야 합니다.
4. 별칭("집", "회사"), 아이콘, 색을 지정하면 위젯에서 구분하기 쉽습니다.
5. **"이 장소를 기억하기"** 를 켜 두면 위치 기반 자동 정렬이 동작합니다.
6. 목록에서 한 번 탭해 전환이 되는지 확인합니다.
   - 첫 연결에는 iOS 가 확인 창을 띄웁니다 → **연결** 을 누르세요.
   - 위치 권한을 묻는 창이 뜨면 **"앱을 사용하는 동안 허용"** 을 선택하세요.
     (현재 연결된 Wi-Fi 이름을 읽으려면 iOS 가 위치 권한을 요구합니다.)

---

## 8단계 — 홈 화면 위젯 추가

1. 바탕화면 빈 곳을 **길게 누릅니다** (아이콘이 흔들릴 때까지).
2. 왼쪽 상단 `+` 를 누릅니다.
3. **"Wi-Fi 전환"** 을 검색해서 선택합니다.
4. 크기를 고릅니다:
   - **작게** — 2개 표시
   - **중간** — 4개 표시 (추천)
   - **크게** — 8개 표시
5. **위젯 추가** 를 누르고 원하는 위치로 끌어다 놓습니다.

---

## 9단계 — 제어 센터 / 잠금화면 컨트롤 추가 (iOS 18 이상)

1. 화면 오른쪽 위에서 아래로 쓸어내려 **제어 센터** 를 엽니다.
2. 왼쪽 상단 `+` (또는 빈 곳 길게 누르기) → **컨트롤 추가** 를 누릅니다.
3. **"Wi-Fi 전환"** 을 찾아 선택합니다.
4. 추가된 버튼을 탭하면 **어떤 네트워크에 연결할지 고르는 화면** 이 나옵니다.
   하나를 선택하세요.
5. 네트워크마다 버튼을 따로 두고 싶으면 **3~4번을 반복** 합니다.

같은 컨트롤을 **잠금화면**(잠금화면 길게 누르기 → 사용자화)이나
**액션 버튼**(설정 > 액션 버튼, iPhone 15 Pro 이상)에도 배치할 수 있습니다.

## 문제가 생기면

| 증상 | 원인과 해결 |
|---|---|
| 위젯이 "설정 필요" 라고 표시됨 | App Group 불일치. 앱의 **도움말 > 진단** 에서 상태를 확인하고, 5단계로 돌아가 두 타깃에 **같은** App Group 이 체크됐는지 보세요. |
| 위젯이 "등록된 Wi-Fi 없음" | 앱에서 네트워크를 먼저 등록해야 합니다. 이미 등록했다면 App Group 문제입니다. |
| "iOS 는 앱이 화면에 떠 있을 때만…" 오류 | 정상 동작입니다. 위젯 탭 시 앱이 떠야 전환됩니다. 앱이 안 뜨면 재설치해 보세요. |
| "연결 요청을 취소했습니다" | iOS 확인 창에서 취소를 누른 경우입니다. 다시 탭하고 **연결** 을 누르세요. |
| "비밀번호 형식이 올바르지 않습니다" | WPA 는 8~63자, WEP 는 정확히 5자 또는 13자여야 합니다. |
| "현재 연결 확인 불가" 라고만 나옴 | 위치 권한이 없습니다. 설정 > Wi-Fi 전환 > 위치 → "앱을 사용하는 동안". |
| 전환이 되는데 인터넷이 안 됨 | 카페·공항처럼 로그인 페이지가 있는 네트워크입니다. Safari 를 한 번 열어 로그인하세요. |
| 거리/위치순 정렬이 안 됨 | 네트워크 편집에서 "이 장소를 기억하기" 를 켜야 합니다. 그리고 그 장소에서 한 번 저장/연결해야 좌표가 기록됩니다. |
| 7일 뒤 앱이 안 열림 | 무료 개발자 계정의 제한입니다. Xcode 로 다시 `⌘R` 하거나 유료 가입이 필요합니다. |
| `No such module 'WidgetKit'` 등 빌드 오류 | `xcodegen generate` 를 다시 실행하고 Xcode 를 닫았다 여세요. |

### 그래도 안 되면

빌드 오류 메시지 전문이나 화면 사진을 그대로 알려 주세요.
특히 **Xcode 의 빨간 오류 메시지 전체 문장** 이 있으면 바로 고칠 수 있습니다.
